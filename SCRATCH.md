# Scratch / smoke checks

## frontend-ui (liquid glass)

1. `npm run dev` — open client; PlateWise logo + frosted glass panels on leafy background.
2. Toggle prefs (Vegetarisch / Vegan / Halal); recipe list updates.
3. Tap **Match producten** on a recipe → match tab with thumbs, swap select, uncheck rows → add to list.
4. List tab: total bar, Reminders, Clear. Switch EN/NL; resize to phone width (~375).
